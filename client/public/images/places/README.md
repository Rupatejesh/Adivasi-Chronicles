# District journey photographs

The active slots and future extensions are in `src/data/journeyPlaces.js`.
No place photographs are supplied. The scenic background is a labelled CSS
illustration, not a photograph of a named location. After reviewing genuine
user-supplied local photography, set the matching approved flag and alt text.
Do not download substitutes, invent credits or treat CSS scenery as documentary.
Missing or failed assets retain readable labels and the landscape fallback.
